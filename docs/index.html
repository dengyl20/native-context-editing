The idea

Context editing, made native

A rule fires on size alone and cannot tell which information the task still needs. A tool call takes its meaning from a schema the harness declares in the prompt. NCE makes the edit part of the language the model already speaks, so its meaning ships with the model and holds in every harness.

Vocabulary

Dedicated tokens

Seventy reserved tokens name the pieces of an edit. Address tokens name a block; operator tokens say what happens to it.

<sid_hi_12><sid_lo_07> drop rewrite append
Composition rules

Well-formed edits

An edit is one envelope around one operator. The rules are small enough to state in a line each, and a malformed envelope executes as a no-op.

<ctx> </ctx>
Semantics

One edit, one transition

Each well-formed edit binds to exactly one transition of the context state, executed by a task-agnostic runtime, in every harness.

St+1 = Execute(St, et)
drop <ctx> <op_drop> <sid_hi_00><sid_lo_04> <sid_hi_00><sid_lo_11> </ctx> Remove the listed blocks and retire their addresses for good.
rewrite <ctx> <op_rewrite> <sid_hi_00><sid_lo_04> The migration touches three tables… </ctx> Replace one block’s text, keeping its address.
append <ctx> <op_append> Suite passes once the cache is cleared first. </ctx> Add the text as a note under a fresh address.

Method

From recorded trajectories to a learned editing policy

Recorded trajectories contain no edits. Two teachers annotate them, and training follows the context as it is edited, so each decision is supervised on the context the agent will actually face.

Recorded trajectories

Long-horizon runs from Terminal-Bench and SWE-bench, with no edits of any kind.

Offline release teacher

Reads the full trajectory and assigns each block a release point: the turn after which it may be edited. A block is released only when the teacher can cite the event that ended its use.

Online edit teacher

Sees only the blocks and the release annotations available at that turn, and decides when and how to edit. The edits are therefore safe to learn and executable by an agent that cannot see ahead.

Evolving-context distillation

Each edit executes at the end of the turn that issues it, and every later decision is built on the resulting context, matching inference time exactly.

Deploy

The model generates a turn, the runtime executes the edits it contains, and generation resumes from the edited context.
